| 단계 | 파일 | 내용 |

| 3. 구현 | `code-design/3-implementation.md` | Git Commit |
| 4. 피드백 | `code-design/4-feedback.md` | 테스트 / 평가 / Git Issue·Milestone·PR |

진행은 `/code-design` 커맨드를 사용한다.
