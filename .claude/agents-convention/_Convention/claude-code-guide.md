## 단어
- 프롬프트 : 사용자가 AI에게 주는 명령이나 질문
- 컨텍스트 : 프롬프트를 이해하고 올바르게 처리하기 위한 배경 정보
- 토큰 : AI가 글자를 읽는 최소 단위
- 컨텍스트 윈도우 : 한 번에 기억할 수 있는 텍스트의 양(토큰 단위)
- 컨텍스트 롯 : 작업이 끝나고 곧바로 작업을 진행할 때, 이전 작업의 잔해가 남아있어 다음 작업에 영향을 줌. 토큰을 잡아먹으면서 동시에 혼란을 줌
- 환각 : 관련없는 정보가 많아지면, 컨텍스트 롯이 심해지면 발생함. AI가 틀린 답을 자신 있게 말함.


#### 컨텍스트 관리
- AI는 매 메시지마다 이전 대화를 전부 다시 읽는다. -> 매 작업마다 `/clear`를 통해서 대화를 비워준다.
- `/rename`으로 세션의 이름을 지정해 두며, 대화를 비워도 기록이 남아 쉽게 돌아갈 수 있다.
- Extended Thinking : AI가 내놓은 결과가 예상과는 다를 때, AI의 논리 흐름을 추적하고 어느 지점에서 실수가 발생했는지 파악 가능 




### 클로드 모델
- Pro 요금제에서 Sonnet 모델은 주당 40~80시간 사용가능
- Pro 요금제에서 Opus 모델은 매우 제한적

- Opus : 가장 똑똑, 토큰 4~5배 소모. 복잡한 설계나 어려운 버그에 사용
- Sonnet : 균형 잡힘, 대부분 작업 충분. 일반 코딩이나 파일 수정, 기능 구현 등
- Haiku : 가장 빠르고 저렴. 간단한 질문이나 파일 검색
