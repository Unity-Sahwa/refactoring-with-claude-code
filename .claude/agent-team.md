# Agent Team 정의

> 출시된 게임 프로젝트(Sahwa)의 코드 리팩토링을 위한 에이전트 팀 구성

---

## 팀원 정의

---

### 분석담당
- 원본 코드 문제 진단 및 구현된 코드 검증

#### 업무
- 업무 지침에 따른 원본 코드 분석
- 업무 지침에 따른 코드 피드백
- 업무 지침에 따른 코드 검증(테스트)
- 업무 지침에 따른 보고서 작성

---

### 설계담당
- 분석 결과를 토대로 구현 명세 작성


#### 업무
- 업무 지침에 따른 설계 명세 작성
- 업무 지침에 따른 보고서 작성

---

### 구현담당
- 설계 명세를 코드로 실현


#### 업무
- 설계 문서와 업무 지침에 따른 코드 리펙토링
- 업무 지침에 따른 보고서 작성


---

### 보조 담당
- 사용자 보조 담당
- git 관련(commit 작성, branch 생성, PR 작성, Issue 작성) 글 작성


#### 업무
- 업무 지침에 따른 문서 작성
- 업무 지침에 따른 보고서 작성
