# 주석 컨벤션

> 원칙: ** 오직 코드를 작성한 "왜"를 주석으로 적는다.**
> `Old/` 폴더와 실험용(`_Test`) 코드는 검사 대상에서 제외한다.

---

## 0. 검사·보고 절차

1. 대상 `.cs` 파일을 직접 읽는다. 추측하지 않는다.
2. 아래 1~4절과 대조해 위반을 찾는다. **빠진 주석과 과한 주석 둘 다 위반이다.**
3. **코드를 수정하지 않는다. 보고만 한다.**
4. 아래 형식의 표로 출력한다.

| 파일:줄 | 규칙 | 현재 | 제안 |
|---|---|---|---|
| PlayerController.cs:12 | 1절 흐름 주석 누락 | 없음 | 흐름 한 줄 추가 |
| PlayerController.cs:88 | 3절 코드 반복 주석 | `// 체력을 감소시킨다` | 삭제 |
| AudioPlayer.cs:10 | 1절 2줄 초과 | 세 번째 줄 | 삭제 |

- 위반이 없으면 `위반 없음` 한 줄만 출력한다.
- 규칙 칸에는 반드시 절 번호를 적는다.

## 1. 클래스 주석

**모든 public 클래스에 필수.** 표기는 `// 책임:` / `// 흐름:` 로 고정한다.

```csharp
// 책임: 피격을 받아 체력을 깎고, 죽었는지 판정한다. (데미지 계산은 DamageCalculator 담당)
// 흐름: 피격 → 방어력 적용 → 체력 감소 → 0 이하면 사망 이벤트 발행
public class PlayerHealth : MonoBehaviour
{
}
```

| 항목 | 내용 | 언제 다나 |
|---|---|---|
| 책임 | 한 줄로 무슨 객체인지 | 항상 |
| 흐름 | 한 줄로 단계가 이어지는지 | **단계가 2개 이상일 때만** |

- **최대 2줄.** 책임 1줄 + 흐름 1줄. 3줄 이상이면 위반이다.
- 넘긴 책임은 책임 줄 끝 괄호에 적는다 — `(데미지 계산은 DamageCalculator 담당)`.
- 아래는 주석 없어도 위반이 아니다.
  - 데이터만 담는 클래스·구조체 (`~Data`, DTO)
  - 메서드 하나짜리 인터페이스 (`IVolumeControl`)
- 책임을 한 줄로 못 쓰면 클래스가 여러 일을 하고 있다는 신호다.
- 흐름에 "그리고", "또"가 계속 붙으면 책임 분산 신호다.

## 2. 메서드 주석

- **원칙: 자명하지 않을 때만 "왜"를 단다.**
- 아래는 주석 없어도 위반이 아니다.
  - getter·setter, 단순 위임
  - `Awake`의 단순 참조 연결
  - 이름만 읽어도 동작이 그대로 보이는 한 줄 메서드
- 아래는 주석이 있어야 한다.
  - 함정이 있는 코드 (실행 순서 의존, 유니티 생명주기 타이밍 등)
  - 비직관적 선택 (왜 이 방식을 골랐는지)

```csharp
// 슈퍼아머 상태에서는 경직이 없으므로 피격 애니메이션만 재생한다.
private void PlayHitReaction()
{
}
```

- public 메서드에는 XML summary를 써도 된다 (IntelliSense 지원).
```csharp
/// <summary>
/// 플레이어에게 데미지를 입힌다.
/// </summary>
public void TakeDamage(int amount) { }
```

## 3. 줄 단위 주석

- 비직관적인 줄(트릭, 수식, 한눈에 안 들어오는 API) **위에** 설명을 단다.
- 코드를 그대로 옮겨 적는 주석은 위반이다.

```csharp
// X — 코드 반복
_health -= amount; // 체력을 amount만큼 감소시킨다

// O — 이유 설명
// 프레임 독립적으로 만들기 위해 deltaTime을 곱한다
_position += _velocity * Time.deltaTime;
```

---

## 4. 서식·금지 사항

- `//` 뒤에 공백 하나 — `// 내용`
- 한국어 사용 (이 프로젝트 규칙)
- 코드 줄 끝이 아닌 **별도 줄**에 작성
- 주석 처리된 코드는 삭제 (버전 관리로 복원 가능)
- `TODO` 주석은 작업 완료 시 즉시 삭제
- 모든 줄에 주석이 달려 있으면 위반 — 잘 지은 이름이 최고의 주석이다

### SerializeField 설명은 Tooltip으로
```csharp
[Tooltip("이동 속도 (m/s)")]
[SerializeField] private float _moveSpeed;
```
