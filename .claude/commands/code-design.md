# 코드 설계 진행

아래 4단계를 순서대로 진행한다.
각 단계를 시작할 때 해당 규칙 파일을 **읽고**, 그 규칙에 따라 사용자와 대화하며 진행한다.

## 진행 원칙
- 한 번에 큰 출력을 쏟지 않는다. 작은 결정 단위로 쪼개 사용자와 합의하며 진행한다.
- 한 단계가 끝나면 사용자 확인을 받고 다음 단계로 넘어간다.
- 단계를 건너뛰지 않는다.
