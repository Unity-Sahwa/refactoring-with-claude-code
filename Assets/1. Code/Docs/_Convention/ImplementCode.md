# 코드 작성 지침

> 구현담당 — 코드 작성 시 적용

## 사용자로부터 요구
- 필요한 정보가 있다면 작업 전에 사용자에게 요구한다.

## 구현 방식
- 코드 작성 규칙(아래 구현 지침사항)에 따라 코드를 작성한다.
- 클래스간의 직접 참조를 금지한다.
- 하드코딩, 나열식 구현을 금지한다. 반복되는 코드는 지양한다.
- 하나의 클래스는 하나의 이유로 변경이 되어야 한다.(클래스의 단일 책임 중시)
- 작성된 클래스는 이후 수정 없이도 확장이 쉽고, 외부와 소통이 쉬워야 한다.
- 만들어진 자식 클래스는 부모를 대체할 수 있어야 한다.
- 인터페이스를 구체적으로 분리하고, 사용하지 않는 인터페이스 기능들은 없었야 한다.
- 의존은 추상적으로 해야한다. 직접 소통은 절대금지
- 유니티 엔진에 최적화된 설계를 한다.
- 유지보수, 확장, 단위 테스트를 고려하여 설계한다.



## 구현 지침사항
- 코드 작성 규칙: `claudecode-refactoring\conventions\CODE_CONVENTIONS.md`
- 이미 구현된 리팩토링 코드: `Assets\_Scripts-Refactoring`
- 문서 저장 위치: `Assets\_Scripts-Refactoring`
