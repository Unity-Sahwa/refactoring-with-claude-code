# Scripts-Origin 구현 기능 목록

원본 코드를 보고, 다시 만들 때 구현해야 할 기능들을 정리한 문서.
클래스 단위로 나누고, 클래스 안에서 책임(기능)별로 한 줄씩 요약한다.

---

# Camera

## CameraController (싱글톤, 메인 카메라 총괄)

- 카메라 종류를 3가지로 구분한다 (기본 / 락온 / 마무리스킬).
- 자기 자신을 싱글톤으로 등록하고, 중복되면 스스로 삭제한다.
- 게임 시작 시 기기 화면 비율에 맞춰 해상도를 다시 계산해서 적용한다 (안드로이드 720p / 그 외 1080p 기준).
- 프레임을 60으로 고정한다.
- 시작 시 외부 객체(플레이어, 저장매니저, 마스크, 데이터 등)들을 연결하고 카메라 초기값을 세팅한다.
- 시네머신 카메라들(기본/락온/마무리)에서 세부 제어용 컴포넌트를 미리 꺼내둔다.
- 메뉴 화면이 켜져 있으면 카메라 회전 속도를 0으로 막고, 아니면 저장된 마우스 속도를 적용한다.
- PC 플랫폼 여부에 따라 카메라가 마우스 입력으로 회전할지 말지를 켜고 끈다.
- 카메라 종류를 받아 그에 맞는 시네머신 카메라만 켜고 나머지는 끈다.
- 카메라를 전환한 직후 2초 동안 카메라의 높이/거리/오프셋 값을 강제로 유지시킨다 (기본/락온 각각, 보스씬이면 다른 값 적용).
- 마우스 회전 속도를 X축/Y축 따로 설정하거나 읽어온다.
- 보스룸에 들어가면 카메라 거리/높이/오프셋을 보스전용 값으로 바꾼다.
- 매 프레임 주변의 적을 구 범위로 탐지한다 (시야각·거리·사망 여부로 걸러냄).
- 탐지된 적 중 가장 가깝거나 정면에 가까운 적 하나를 "보이는 타겟"으로 고른다.
- 주변에 적이 감지되면 플레이어 HUD를 잠깐 띄운다.
- 타겟의 칠하기(페인트) 스택이 가득 찼는지 확인하고, 튜토리얼 상황이면 마무리 공격 가이드를 띄운다.
- "보이는 타겟"이 있으면 그 적 외곽선(아웃라인)을 그리고, 타겟이 바뀌거나 사라지면 외곽선을 지운다.
- 외곽선은 적의 자식 오브젝트(OutlineTarget 태그) 머티리얼 배열에 외곽선 머티리얼을 추가하는 방식으로 그린다.
- 락온 중인 타겟이 죽거나 너무 멀어지면, 주변에 다른 적이 있으면 자동으로 그 적에게 락온을 옮기고 없으면 락온을 푼다.
- 락온을 풀면 타겟 그룹·애니메이터·내부 변수들을 초기화하고 기본 카메라로 되돌린다.
- 타겟 머리 위에 화면상 마커(UI 이미지)를 띄우고, 락온/단순감지 상태에 따라 마커 색을 다르게 한다 (월드 좌표를 화면 좌표로 변환).
- 락온 버튼을 누르면 타겟을 지정해 락온 카메라로 전환하고, 락온 중 다시 누르면 락온을 해제한다 (토글).
- 조이스틱 좌우 입력으로 카메라를 수평 회전시킨다.

## SetBossRoomCamera (이벤트로 실행되는 카메라 세팅)

- 이벤트 데이터(EventData)를 상속받아, 실행되면 카메라의 기본값 유지 코루틴을 돌린다 (보스룸 진입 연출용 트리거).

## CameraData (카메라 설정값 묶음, ScriptableObject)

- 락온 탐지 관련 설정값을 모아둔다 (탐지 거리, 가깝다고 판단하는 거리, 적/장애물 레이어, 시야각, 최대 거리).
- 타겟 마커 관련 설정값을 모아둔다 (마커 위치 보정, 크기, 감지 색상, 락온 색상).
- 카메라 좌우 스와이프 속도 비율을 설정값으로 가진다.
- 이 설정 데이터를 싱글톤으로 불러오고, 에디터에서 파일이 없으면 자동으로 만들어준다 (Resources 폴더 기반).

# Player / Control

## MobileInput (모바일 버튼 입력 → 스킬 연결, 싱글톤)

- 자기 자신을 싱글톤으로 등록하고 중복되면 삭제한다.
- 모바일 화면 버튼이 호출하는 입력 진입점들을 모아둔 클래스다 (실제 동작은 각 스킬 클래스에 위임).
- 기본 공격 버튼: 현재 마스크(인간/동물)에 따라 해당 마스크의 기본 공격을 실행하고, 입력을 버퍼에 저장한다.
- 특수 공격 버튼: 인간이면 잉크 형상, 동물이면 도약 공격을 실행하고 입력을 저장한다.
- 마무리 공격 버튼: 고스트 마무리 스킬을 실행하고 입력을 저장한다.
- 대시 버튼: 현재 마스크의 대시를 실행하고 입력을 저장한다.
- 스킬 실행 전 항상 "스킬 수행 중인지"를 검사해 중복 실행을 막는다.
- 락온 버튼: 카메라 컨트롤러의 락온을 호출한다.
- 메뉴 버튼: 메뉴 UI를 연다.
- 상호작용 가능/불가 상태를 켜고 끈다 (다른 시스템이 이 플래그를 참조).

## TimelineHelper (컷신/타임라인 연출 제어, 싱글톤)

- 자기 자신을 싱글톤으로 등록하고 중복되면 삭제한다.
- 씬 시작 시 첫 번째 씬 + 메인메뉴 활성 여부로 "튜토리얼 씬"인지 판단하고, 그에 맞게 플레이어 위치/조작 잠금을 세팅한다.
- 튜토리얼 씬일 때만 새 게임 시작 카메라를 켜고, 아니면 끈다 (없으면 경고 로그).
- 튜토리얼 시작 타임라인을 재생한다 (화면 페이드 → 플레이어 위치 이동 → 메뉴 창들 끄기 → 타임라인 재생 순서의 코루틴).
- 튜토리얼 시작 연출을 건너뛴다 (요소 비활성화, 커서 상태 플랫폼별 처리, 카메라/타임라인 끄기, 조작 복구).
- 등록된 타임라인 배열 중 하나라도 재생 중인지 확인한다.
- 플레이어 조작을 잠그거나 푼다 (잠금 시 사운드 정지·상태 초기화·마우스 입력 0·HUD 처리, 해제 시 마우스 데이터 로드·물리 복구·커서 상태 처리).
- 화면을 어둡게(페이드아웃) / 밝게(페이드인) 전환한다 (UIEffect에 위임).

## PlayerController (플레이어 총괄 + 키보드 입력 분배, 싱글톤)

- 자기 자신을 싱글톤으로 등록하고 중복되면 삭제한다.
- 시작 시 데이터 싱글톤들과 하위 컴포넌트(마스크변경/이동/스킬/플레이어 등)를 모두 연결하고 마스크를 초기화한다.
- 매 프레임 메뉴 키 입력을 받아 메뉴를 토글한다.
- 조작 잠금/사망 상태면 이후 로직을 막는다 (가드 처리).
- 매 프레임 애니메이션 상태를 갱신한다.
- 스킬 쿨다운 중이거나 적이 감지되면 플레이어 HUD를 페이드 표시한다.
- 매 프레임 마스크 변경·피격·각 스킬들의 쿨다운을 갱신한다 (현재 마스크에 따라 인간/동물 스킬 쿨다운 분기).
- 락온 키 입력을 받아 카메라 락온을 호출한다.
- 매 프레임 이동 입력을 처리한다 (PlayerMovement에 위임).
- 조작 차단(doNotAct) 상태가 아니면 매 프레임 마무리 공격이 가능한 적을 탐지한다 (고스트 스킬에 위임).
- PC 플랫폼일 때만 키보드로 기본/특수/대시/마무리 공격 입력을 받아 현재 마스크의 스킬을 실행한다 (입력 버퍼 저장 포함).
- FixedUpdate에서 Player 오브젝트가 캐릭터를 따라가게 하고, 치트 비행 모드가 아니면 추가 중력을 적용한다.
- FixedUpdate에서 스킬에 의한 이동을 갱신하고, 조작 가능 상태면 캐릭터 회전·이동을 실행한다 (상태 플래그로 회전/이동 개별 차단).

## MaskChange (가면/캐릭터 교체, 싱글톤)

- 자기 자신을 싱글톤으로 등록하고 중복되면 삭제한다.
- 시작 시 데이터 싱글톤 연결 후 인간/동물 캐릭터 오브젝트·애니메이터·리지드바디를 자식에서 찾아 초기화한다.
- 인간/동물/현재 캐릭터에 대한 오브젝트·애니메이터·리지드바디를 외부에 제공한다 (프로퍼티).
- 캐릭터를 교체한다 (위치·회전 복사, 현재 캐릭터 참조 전환, 스킬 초기화, 활성/비활성 토글, 락온 포커스 동기화).
- 가면을 교체한다 (HUD 아이콘 변경, 마스크 오브젝트 표시 전환, 파트너 충돌 연출, 마스크별 이펙트·사운드 재생, 인간/동물/고스트 분기).
- 캐릭터 교체에 쿨다운을 두고, 시간이 지나면 다시 사용 가능하게 한다.

## PlayerMovement (이동·회전 입력 처리, 싱글톤)

- 자기 자신을 싱글톤으로 등록하고 중복되면 삭제한다.
- 시작 시 저장매니저·마스크변경·공통데이터를 연결한다.
- 키보드 입력을 부드러운 이동값으로 변환한다 (좌우/상하 각각, 눌린 순서를 부호 배열로 기억해 가장 최근 입력을 우선, 시간에 따라 가감속).
- 이동 입력을 받아 플랫폼별로 처리한다 (모바일=조이스틱 직접값 / PC=가감속 변환값).
- 이동 입력 크기에 따라 카메라 리센터링을 켜고 끈다 (모바일).
- 입력값으로 이동 벡터와 애니메이터 파라미터(horizontal/vertical/moveAmount)를 갱신한다.
- 이동 방향을 카메라 기준으로 회전시켜 목표 회전값을 계산하고, 락온 중이면 타겟 방향으로 목표 회전을 잡는다.
- 현재 마스크에 따라 이동 속도를 결정한다 (인간/동물 데이터, 치트 모드면 치트 속도).
- 캐릭터를 목표 회전으로 회전시킨다 (락온 시 Slerp, 평상시 RotateTowards).
- 캐릭터를 이동시킨다 (리지드바디 MovePosition, 센서가 전방 막힘이면 속도 0, 비행 치트 시 상승 속도 추가).
- 캐릭터에 추가 중력을 가한다.
