"Stat(스킬스탯)"
	damage -> 스킬 데미지
	cooldown -> 스킬 쿨타임
	inkStack -> 이 스킬로 공격하면 쌓이는 잉크스택
	
"Move(스킬이동)"
	direction -> 이동이 적용되는 방향
	moveSpeed -> 이동 속도
	waitTime -> 스킬을 사용하고 waitTime(지연시간) 이후에 이동 시작
	duration -> 이동을 시작하고 duration(지속시간) 이후에 이동 중지

"Restrict(스킬 행동제한)"
	actRestrictWaitTime -> 스킬을 사용하고 waitTime(지연시간) 이후에 행동제한 시작
	actRestrictDuration -> 행동 제한하고 duration(지속시간) 이후에 행동제한 중지
	moveRestrictWaitTime -> 이동 제한 지연시간
	moveRestrictDuration -> 
	rotateRestrictWaitTime
	rotateRestrictDuration

"Animation Speed(애니메이션 속도)"
	+버튼으로 구간 추가가능
	구간별로 애니메이션 속도 조절 가능. 
	영역이 서로 겹치지 않도록 하기
	ex) 1번 구간은 0~0.5까지 속도 2, 2번 구간은 0.5에서 1까지 속도 1
	
	startTime 구간시간부분
	endTime 구간끝부분
	animationSpeed 구간 내 속도
	
"Effect(스킬 이펙트)"
	waitTime -> 스킬을 사용하고 waitTime(지연시간) 이후에 이펙트 켜짐
	duration-> 이펙트 켜지고 duration(지속시간) 이후에 이펙트 꺼짐
	
	(이펙트 이동,회전, 크기는 이펙트에 아직 미숙해서 이상할 수 있음)
	untilFinish -> 체크해제시, 플레이어가 다른 행동을 하면 이펙트도 바로 사라짐.
	positionOffset -> 이펙트 위치를 추가적으로 이동
	rotationOffset -> 이펙트 위치에서 추가적으로 회전
	scale -> 이펙트 사이즈 조절
	followPosition -> 체크 시 타겟(플레이어나 적)이 움직이면 따라서 움직임
	followWaitTime -> (followPosition 체크시 적용) 스킬 실행하고 waitTime(지연시간)이후에 타겟을 따라감
	followDuration -> (followPosition 체크시 적용) 스킬 실행하고 duration(지속시간)이후에 타겟 따라가기 중지

"무기형상"
	WeaponwaitTime -> 스킬을 사용하고 waitTime(지연시간) 이후에 무기형상 켜짐
	WeaponDuration -> 무기형상 켜지고 duration(지속시간) 이후에 무기형상 꺼짐

"히트박스"
	HitBoxWaitTime -> 위설명과 동일
	HitBoxDuration -> 위 설명과 동일
	HitCount -> 타격 횟수
	HitInterval -> 히트박스 켜지는 간격
	HitBoxScale -> 히트박스 크기(이건 지금 제대로 안적혀있는 것 같음 ㅈㅅㅈㅅ)

"Sound(스킬소리)"
	audioClip -> 소리 여러개 넣을 수 있음(넣은 소리들은 랜덤재생 됨)
	loop -> 체크시 반복(loop키고 untilFinish 키면 무한반복되니 주의)
	volume -> 소리 크기
	pitch -> 소리 속도
	waitTime -> 위에 waitTime 설명과 같음

	spatialBlend -> 0~1 1로 갈수록 거리감이 생겨서 머리있는 소리는 멀게 느껴짐 
	MinDistance -> 소리가 생긴 지점에서 소리가 들리는 최소거리
	MaxDistance -> 소리가 생긴 지점에서 소리가 들리는 최대거리
	untilFinish -> 체크해제시, 플레이어가 다른 행동을 하면 소리 바로 꺼짐.

"CameraShake(스킬 카메라 쉐이크)"
    cameraType -> 삭제 예정
    waitTime -> 위의 waitTime 설명 참고
    shakeType -> 유니티 내에 있는 흔드는 타입들
    impulseVelocty -> 쉐이크 방향과 크기를 x,y,z 벡터로
    impulseDuration -> 쉐이크 지속시간. 지속시간이 클수록 속도가 늘어남(?). 직접적용하면서 느끼기ㄱㄱ
    reactionType ->  쉐이크에 카메라가 반응하는 타입(희안한게 많음..)
    amplitudeGain -> 값을 높이면 카메라 흔들림의 강도가 증가
    frequencyGain -> 값을 높이면 카메라 흔들림의 속도가 증가
    reactionDuration -> 반응하는 시간

"TimeScale(게임속도)"
	timeScale	-> 게임 전체 속도

    	useFrame -> 체크시 아래 프레임 변수들 이용, 체크해제시 아래 초단위(seconds) 이용
	waitTimeFrames -> 위 waitTime 설명 참고
	durationFrames -> 위 duration 설명 참고

	waitTimeSeconds -> 위 waitTime 설명 참고
	durationSeconds -> 위 duration 설명 참고
