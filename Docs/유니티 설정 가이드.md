# 최적화

## RPAsset
- Rendering
	- Inspector 우측 상단 점 3개 클릭 > Show All Advanced Properties 클릭 > 더 자세한 옵션 제공
	- Opaque Texture
		- 의미
			- - 체크 시, 렌터링 파이프라인에서 투명 물체를 그리기 직전의 화면을 한 장의 텍스쳐로 복사해(_CameraOpaqueTexture) 투명 셰이더가 읽을 수 있게 함.
			- - 체크 해제시, 투명 셰이더가 자기 뒤에 그려진 텍스쳐를 가져다 쓸 수 없게 됨. 굴곡 셰이더 같이 화면 픽셀의 입력을 받아 변형하는 셰이더의 경우 깨지게 됨.
		- 문제
			- - 풀스크린 복사 1회라 대역폭(GPU와 메모리 사이 데이터 왕복 부담)이나 메모리 부담(복사본을 담을 공간을 GPU 메모리에 계속 잡아둠)
		- 적용방식
			- 굴절 같은 셰이더가 적용되지 않는다면 무조건 체크 해제
			- 적용한다면 Opaque DownSampling 적용
				- 2x bilinear : 1/4로 축소, 보간 적용
				4x box : 1/16로 축소
				4x bilinear : 1/16로 축소, 보간 적용
	- Terrain Holes
		- 의미
			- 터레인 지형에 구멍을 뚫는 기능
		- 문제
			- 체크시, 매 프레임 화면에 보이는 지형 픽셀마다 구멍인지 물어봄.
