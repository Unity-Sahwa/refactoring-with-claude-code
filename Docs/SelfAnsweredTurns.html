Claude Code 자문자답 문제 기록

Claude Code가 응답을 마치지 않고, 뒤이어 오지도 않은 사용자의 말을 스스로 지어내 이어 쓰는 문제가 있었습니다. 이 문서는 그 사례들을 세션 로그에서 모아, 무엇이 진짜 응답이고 어디부터 지어낸 부분인지 구분해 정리한 기록입니다.

기준

수집 위치 — Unitysahwa-refactoring 프로젝트 폴더

수집 방식 — ~/.claude/projects/*/*.jsonl의 type:"assistant" 메시지를 전부 훑어, 텍스트 블록 안에서 줄 첫머리가 user로 시작하는 지점을 찾음. 그 지점부터는 모델이 스스로 지어낸 가짜 발화로 보고 실제 응답과 분리함. timestamp를 로컬 시각으로 환산해 날짜·시간을 매김.

작성 방식 — 날짜 → 세션 → 시간 순으로 묶어 나열함. 평소엔 시각 칩만 보이고, 클릭하면 직전 사용자 발화·실제 모델 응답·지어낸 가짜 발화·그 다음 사용자 반응이 표로 펼쳐짐.
