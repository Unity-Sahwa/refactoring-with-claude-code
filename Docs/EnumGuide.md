# 직렬화되는 Enum 다루기

씬·프리팹·ScriptableObject에 저장되는 enum(`AudioId` 등)은 **이름이 아니라 정수값**으로 직렬화된다.
값이 바뀌면 이미 배치해둔 참조가 전부 다른 항목을 가리킨다.

## 1. 값을 명시한다

암묵적 순번에 의존하면 중간에 항목 하나만 추가해도 그 뒤가 전부 한 칸씩 밀린다.

```csharp
public enum AudioId
{
    None = 0,

    // 사람탈
    HumanNormalAttack1 = 1,
    HumanNormalAttack1Hit = 2,
    ...
}
```

값이 고정돼 있으면 **어디에 무엇을 추가하든 기존 배치는 안 밀린다.**

## 2. 그룹별로 번호대를 띄운다

```
0        None
1~99     사람탈
100~199  동물탈
200~299  플레이어 공용
300~399  UI
```

가독성용이고, 그룹 끝에 여유 칸이 있어 새 항목을 자기 그룹 안에 붙일 수 있는 게 실익이다.
**단, 이 체계는 프로젝트 시작 시점에 잡아야 한다.** 이미 배치가 끝난 뒤 번호대를 바꾸면
씬·프리팹·에셋을 전부 재지정해야 한다.

## 3. 항목 삭제 / 추가 규칙

- 추가: 자기 그룹의 최대값 + 1. 중간 빈 번호를 재사용하지 않는다.
- 삭제: 값을 회수하지 않는다. 지운 자리에 다른 항목을 넣으면 옛 데이터가 그 항목을 가리킨다.
- 이름 변경은 안전하다(값이 그대로면 직렬화 데이터는 영향 없음).

## 4. 이미 밀렸다면

번호를 되돌리는 게 가장 싸다. 그게 불가능하면 씬·프리팹·에셋의 저장값을 일괄 치환하거나
에디터에서 수동 재지정하는 수밖에 없다.
